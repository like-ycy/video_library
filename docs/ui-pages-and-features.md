# 视频库 App 页面与功能点

本文用于 Stitch UI 设计，描述页面层级、主要组件和用户操作。功能按三期规划标记。

## 页面总览

```text
应用壳
├── 观影
│   ├── 视频库/演员浏览
│   ├── 继续观看
│   ├── 最近播放
│   └── 视频详情
├── 刮削
│   ├── 扫描结果
│   ├── 刮削任务详情
│   └── 失败与问题列表
├── 设置
│   ├── 视频库管理
│   ├── 刮削器设置
│   ├── 播放器设置
│   ├── 环境诊断
│   └── 外观设置
└── 关于 / 更新（第三期）
```

全局顶部区域：应用名称、主导航、当前视频库选择器、添加视频库、全局状态提示、设置入口。

## 一、观影模块

### 1. 观影首页 / 演员浏览

这是默认首页，用于按演员浏览整个视频库。

功能点：

- 视频库切换。
- 演员侧栏或顶部标签。
- “全部演员”入口。
- 演员视频数量。
- 演员存在缺失文件时显示提示标记。
- 视频卡片网格。
- 卡片展示封面、番号、标题、发布日期、文件大小、真实时长。
- 收藏标记。
- 文件缺失标记。
- 点击卡片进入视频详情。
- 点击卡片封面直接播放。
- 封面懒加载。
- 无封面时显示占位图。
- 无结果、索引为空、视频库不可访问等空状态。

筛选与排序：

- 搜索番号或标题。
- 按类别筛选，可多选。
- 仅看收藏。
- 按演员、发布日期、文件大小、真实时长、标题、番号、刮削时间排序。
- 升序/降序切换。
- 分页或加载更多。

### 2. 继续观看

第一期功能。

功能点：

- 展示有播放进度但尚未看完的视频。
- 显示上次播放位置和总时长。
- 显示进度条和百分比。
- 点击后从上次位置继续播放。
- 清除播放进度。
- 播放完成后从列表移除，或允许重新播放。
- 无记录时显示空状态。

### 3. 最近播放

第一期功能。

功能点：

- 按最近播放时间倒序展示。
- 显示最后播放时间、播放次数和播放进度。
- 点击继续播放。
- 清空最近播放记录。
- 无记录时显示空状态。

### 4. 视频详情

功能点：

- 大封面。
- 标题、番号、演员、发布日期、类别。
- 站点标注时长与文件真实时长分开显示。
- 分辨率、视频编码、音频编码。
- 文件大小、文件名、刮削时间。
- 收藏/取消收藏。
- 评分设置与清除评分。
- 播放进度展示。
- 截图缩略图墙。
- 截图灯箱预览、上一张/下一张、关闭。
- 内嵌视频播放器。
- 播放、暂停、进度拖动、音量、全屏。
- 自动保存播放进度。
- 播放失败时提示使用外部播放器。
- 外部播放器打开。
- 关闭详情后停止播放并清理播放器。

第二期功能：

- 同番号多个视频版本选择，例如普通版、字幕版、4K 版。
- 显示每个版本的文件名、分辨率、编码、大小。
- 切换版本后从当前版本开始播放。
- “播放下一个”按钮。
- 当前演员视频播放列表。
- 播放结束自动进入下一个，可由用户关闭。

## 二、刮削模块

### 1. 刮削首页 / 扫描结果

功能点：

- 当前视频库选择。
- 扫描视频库。
- 更新索引。
- 重建索引。
- 显示扫描到的视频总数。
- 按演员、番号、文件名、文件大小展示候选列表。
- 状态标记：未刮削、已刮削、缺图、文件异常。
- 未识别番号的问题列表。
- 边车 JSON 损坏的问题列表。
- 默认只显示未刮削和缺图条目。
- 全选当前可见条目。
- 清空选择。
- 重新下载图片选项。
- 开始刮削。
- 没有视频库时引导添加视频库。
- 刮削器未配置时引导进入设置。

### 2. 刮削任务详情

功能点：

- 总体进度条。
- 成功、失败、未处理数量。
- 当前任务状态：准备中、运行中、正在取消、已完成、已取消、异常结束。
- 每个番号的实时状态。
- 当前阶段：搜索、详情页、下载封面、下载截图。
- 单项进度百分比。
- 单项成功结果标题和截图数量。
- 单项失败原因和详细信息。
- 可重试失败项。
- 取消当前任务。
- 取消后保留已经成功的结果。
- 查看最近刮削日志。
- 刮削完成后自动更新索引并提示结果。

### 3. 刮削问题与失败列表

功能点：

- 按问题类型分组：番号无法识别、站点找不到、解析失败、图片下载失败、Chrome 缺失、驱动失败、超时。
- 显示演员、文件名、番号和错误说明。
- 只重试可重试问题。
- 跳转到对应视频文件。
- 提示修复动作，例如重命名文件、安装 Chrome、修改 scraper 路径。

## 三、设置模块

### 1. 设置首页

功能点：

- 分组显示配置项。
- 当前配置保存状态。
- 恢复默认值。
- 修改后立即生效或提示重启。
- 配置文件位置展示。
- 应用数据目录展示。

### 2. 视频库管理

功能点：

- 添加视频库根目录。
- 移除视频库。
- 切换当前视频库。
- 显示库路径、稳定标识、可访问状态。
- 硬盘未连接或路径失效时显示原因。
- 重新扫描库。
- 重建该库索引。
- 明确提示：移除视频库不会删除磁盘文件。

### 3. 刮削器设置

功能点：

- 选择 `scraper.exe`。
- 显示当前 scraper 路径。
- 自动探测标准安装路径。
- 校验文件存在且可执行。
- 显示 scraper 版本与协议版本。
- 运行环境自检。
- 设置并发数。
- 设置单任务超时时间。
- 测试 scraper 是否可启动。
- 路径失效时显示修复指引。

### 4. 播放器设置

功能点：

- 选择外部播放器可执行文件。
- 显示当前播放器路径。
- 使用系统默认播放器。
- 测试播放器启动。
- 默认是否续播。
- 内嵌播放失败时是否自动提示外部播放器。

### 5. 环境诊断

功能点：

- Chrome 是否安装。
- Chrome 路径与版本。
- 浏览器驱动状态。
- 驱动缓存目录与可写状态。
- 临时目录可写状态。
- ffprobe 是否可用。
- ffprobe 路径与版本。
- scraper 版本和协议兼容性。
- 一键复制诊断信息。
- 重新检查环境。

### 6. 外观设置

第一期基础功能：

- 深色主题。
- 浅色主题（如果设计需要）。
- 跟随系统主题。

## 四、应用级页面与状态

### 1. 视频库不可用状态

- 显示库路径。
- 显示不可访问原因。
- 引导重新连接硬盘或重新选择目录。
- 保留索引和用户收藏、评分、播放进度。

### 2. 首次使用引导

- 添加第一个视频库。
- 检查 Chrome。
- 选择或自动发现 scraper.exe。
- 扫描视频。
- 开始第一次刮削。
- 进入观影页面。

### 3. 全局错误与提示

- 成功 toast。
- 可恢复错误 toast。
- 阻断性错误对话框。
- 长任务期间显示全局忙碌状态。
- 网络错误、站点错误和本地文件错误使用不同提示。

## 五、第三期页面

### 1. 更新页面 / 关于

- 当前 App 版本。
- 当前 scraper 版本。
- 当前协议版本。
- 检查新版本。
- 显示更新内容。
- 下载 `video-library.exe` 和 `scraper.exe`。
- 分别更新主程序和刮削器。
- 更新失败后保留旧版本。

### 2. 多站点刮削设置

- 站点列表。
- 启用/禁用站点。
- 站点优先级。
- 站点可用性检测。
- 每个站点的失败统计。
- 选择本次任务使用的站点。

### 3. 字幕管理

- 识别字幕版文件。
- 显示字幕语言或字幕标记。
- 版本筛选：普通版、字幕版、4K 版。
- 默认播放版本设置。
- 字幕文件关联与显示状态。

### 4. 演员资料页

- 演员名称与目录路径。
- 演员封面。
- 视频数量、收藏数量、总时长。
- 演员相关类别统计。
- 演员简介和外部站点资料（如果未来数据源稳定）。
- 演员级收藏与排序。

## 六、 Stitch 设计重点

- 首屏优先展示封面与浏览效率，避免把技术状态放在观影主流程中。
- 刮削页优先展示“哪些文件需要处理”和“当前任务是否安全完成”。
- 设置页优先解决路径、环境和并发配置，不做复杂表单。
- 详情页同时承担查看、播放、收藏、评分、截图浏览和版本选择。
- 所有长任务都需要明确进度、取消状态和失败原因。
- 所有不可访问、无索引、无封面、无搜索结果状态都需要独立设计。
