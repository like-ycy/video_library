# Stitch 新稿返工修订册

针对 `/Users/wang/Downloads/stitch_cinevault_workstation_design_system` 已生成页面的**对话式修订指令**。

- 不要整份粘贴本文件。
- 每节「复制区」一次只发给 Stitch 一轮。
- 改造页一律写「在当前屏上修改，不要重新生成整套布局」，并写清「保持不变」。
- 深色验证页本册不覆盖。
- 配套架构：[`architecture.md`](architecture.md)；页面功能：[`ui-pages-and-features.md`](ui-pages-and-features.md)。
- 从零重画总册见 [`stitch-page-prompts.md`](stitch-page-prompts.md)（本册是出图后的返工，不替代总册）。

## 怎么用

1. 在对应屏的对话里，或新开对话并说明「修改已有屏 <屏名>」。
2. 只复制该节代码块。
3. 改完立刻截图存档。
4. 若 Stitch 整页重画，下一轮在「保持不变」里点名要保住的区块。

## F0 · 全局禁词与路径（优先）

**适用**：继续观看、最近播放、任务监控、扫描与待处理、刮削器设置、环境诊断、全部影片。逐屏各贴一次。

```text
在当前屏上修改文案与展示，不要重做布局与视觉风格。

【全局替换】
1. 删除一切 mpv / libmpv / 渲染器内核 / GPU 解码管线 / D3D11VA / nvdec / ewa_lanczos 字样。
   内嵌播放只允许表述为：WebView2 内嵌 HTML5 video · 本地直读 · 无转码。
2. 删除 NamedPipe / 命名管道 / 匿名管道 IPC 表述。
   scraper 与主程序通信只允许表述为：子进程 scraper.exe · stdin/stdout NDJSON 事件流。

6. 删除微秒级断点、握手码、Unix 风格面包屑（如 LIBRARY_ROOT > MEDIA_SESSION）、
   LOCALHOST_SUBSYSTEM、瞬时吞吐率这类实现向噪音；状态用简短中文说明。

保持不变：侧栏结构、卡片/列表布局、配色与字体、已正确的功能文案。
```
