# Stitch 逐页 Prompt 总册

给 Google Stitch 用的**完整、可独立粘贴**的页面设计指令。

## 怎么用

1. 在 Stitch 新建 **Desktop** 画布项目（不要 Mobile）。
2. 按下面顺序，**每页开一段新对话**（或在同项目里按屏迭代，但不要一次贴多页）。
3. 每页只复制该节「复制区」内的整段文字，一次贴给 Stitch。
4. 出图后立刻截图存档；结果不对就改指令重试，**不要**在一次对话里堆多个页面需求。
5. 产品名：**CineVault**。窗口标题：`CineVault Workstation`。

### 推荐生成顺序

| 顺序 | 编号 | 页面 | 说明 |
|---|---|---|---|
| 1 | P00 | Design System | 先定色板/字体/圆角，后面所有屏挂同一系统 |
| 2 | P01 | 演员首页（默认落地页） | 改动最大、最能定全局气质 |
| 3 | P02 | 视频详情页 | 核心观影页 |
| 4 | P03 | 全部影片 | 平铺网格 + 筛选 |
| 5 | P04 | 继续观看 | 列表页 |

| 7 | P06 | 扫描与待处理 | 刮削入口 |

| 9 | P08 | 异常与修复 | 问题列表 |
| 10 | P09 | 设置 · 视频库管理 | |
| 11 | P10 | 设置 · 刮削器设置 | |
| 12 | P11 | 设置 · 播放器设置 | |
| 13 | P12 | 设置 · 环境诊断 | |
| 14 | P13 | 设置 · 外观与配置文件 | |

### 每页通用注意

- 单次 prompt 过长或 Stitch 整页乱重画 → 把该页再拆成「删元素 / 改布局」两轮。
- 改造已有屏时用「在当前屏上修改」，并写清「保持不变」。
- 界面文案一律简体中文；分组小标题用「中文 · ENGLISH」。
- 不要 emoji 当图标；不要紫蓝渐变模板脸；不要编造 spec 里没有的功能。

## P00 · Design System

**操作**：新建对话，只做设计系统，不画业务页。

```text
请为桌面应用「CineVault Workstation」建立一套完整 Design System，不要生成业务页面。

【产品】
Windows x64 桌面应用，Go + Wails v2 + WebView2。本地视频库管理 + 刮削工具，不是网站、不是 macOS 应用。

【画布】
Desktop，基准 1440×900，最窄 1280×800。

【色彩】
做两套主题变量，只切换色彩、不切换字体：
1) 浅色 Precision —— 背景近白偏冷 #FAF8FF，主色深靛蓝 #3525CD，正文 #131B2E，描边 #C7C4D8
2) 深色 Obsidian —— 背景深紫灰 #14121D，主色淡紫 #D0BCFF，正文 #E6E0F1，描边 #494454

语义色（两主题都要有，通过变量适配深浅）：
- 翠绿 = 正常 / 已刮削 / 成功
- 琥珀 = 警告 / 缺图 / 待处理
- 绯红 = 错误 / 文件异常
- 天蓝 = 进行中 / 任务运行

【字体】统一一套，禁止两主题换字体：
- 标题：Space Grotesk
- 正文：Inter
- 数字与等宽（番号、时长、路径、百分比）：JetBrains Mono

【圆角与密度】
- 控件圆角 8px，卡片 10–12px，弹窗 12px
- 信息密度偏工作台：紧凑但不挤，适合长时间扫列表
- 网格间距 16px，区块间距 24px

【组件样例】（只展示组件，不要完整 App）
1. 按钮：主按钮 / 次按钮 / 纯文字危险按钮（绯红）
2. 状态徽标：未刮削 / 已刮削 / 缺图 / 文件异常（四态，带图标+底色，不要只有颜色）
3. 输入框、下拉选择、开关
4. 视频卡片：2:3 海报比例、左上番号角标、右上收藏心、底部时长与文件大小、状态点
5. 侧栏导航项：选中态、未选中态、带角标数字
6. 表格行 / 列表行

【图标】
统一 Material Symbols Outlined。禁止 emoji 图标。

【禁止】
- 紫蓝渐变背景、三列对称模板布局
- macOS 红黄绿交通灯
- 移动端大触控目标
- 任何业务流程或虚构功能文案

输出：一张可作为全项目基准的 Design System 展示图（组件总览），并标注浅色/深色两套变量。
界面文案用简体中文。
```

## P01 · 演员首页（默认落地页）

**操作**：Desktop 新屏。这是产品默认首页。

```text
这是一个 Windows x64 桌面应用「CineVault Workstation」的界面设计（Go + Wails v2 + WebView2），不是网页、不是 macOS 应用。

请设计默认首页「演员」：按演员浏览本地视频库。

【画布】Desktop 1440×900。

【应用壳（每页都有，本页一并画出）】
- 左侧全局导航栏宽 240–280px，三组：
  观影 · MEDIA：演员（当前页，默认）/ 全部影片 / 继续观看 / 最近播放
  刮削 · SCRAPER：扫描与待处理 / 任务监控 / 异常与修复
  设置 · SETTINGS：视频库管理 / 刮削器设置 / 播放器设置 / 环境诊断 / 外观与配置文件 / 关于与更新
- 顶栏：应用名 CineVault、当前视频库选择器、全局搜索（快捷键 Ctrl+K）、立即扫描、设置入口
- 窗口控制：自绘标题栏，最小化/最大化/关闭在右侧，不要红黄绿交通灯
- 侧栏分组标题格式：中文 · ENGLISH
- 底部状态：Scraper 就绪状态；不要 NAS 容量条

【本页布局】三栏
1. 左侧导航（见上）
2. 演员列表栏，宽约 220px，可折叠
   - 顶部搜索框「搜索演员」
   - 第一项固定：全部演员 (86位)
   - 每行：演员名 + 「N 部」；有缺失文件时右侧琥珀色小标记
   - 当前选中演员高亮
3. 右侧视频网格
   - 标题：「相泽南 · 24 部」（选中时）或「全部演员 · 1262 部」
   - 筛选 chips：全部 / 未看完 / 我的收藏 / 内容类别（题材标签，可多选）
   - 排序：下拉 7 项（演员、发布日期、文件大小、真实时长、标题、番号、刮削时间）+ 升序/降序切换按钮
   - 视图切换：网格 / 列表
   - 分页或加载更多

【卡片】
封面 2:3、番号、标题、演员名、发布日期、文件大小、真实时长、收藏心、文件缺失角标、无封面占位图。
交互提示文案：单击看详情，双击封面直接播放。

【示例数据】
演员：相泽南 24部（2部缺件）、三上悠亚 32部、河北彩花 18部、深田咏美 15部、桥本有菜 11部
视频：IPX-945 · 7.82 GB · 02:18:40 · 已刮削；SSIS-702 · 4.2 GB · 02:05:10 · 缺图；MIDE-890 · 5.1 GB · 01:55:00 · 已刮削；MIDV-112 · 8.4 GB · 02:24:10 · 未刮削；STARS-528 · 6.5 GB · 02:10:00 · 已刮削

【禁止】
- 路径写 Windows 形式（如 D:\Videos\Library），不要 /Volumes 或 smb://
- 不要匹配度百分比、聚合评分、评价人数
- 不要 libmpv、转码、杜比视界、Metal
- 不要具体站点名、代理节点
- 不要 emoji 图标；不要紫蓝渐变三列模板

视觉：专业媒体工作台，信息密度适中，海报墙是主角。
界面文案用简体中文。
```

## P02 · 视频详情页

**操作**：Desktop 新屏。

```text
这是 Windows 桌面应用「CineVault Workstation」（Go + Wails + WebView2）的视频详情页。不是 macOS 应用。

请设计「视频详情」页。应用壳与导航与全局一致：左侧 13 项侧栏（观影/刮削/设置三组）、顶栏搜索与视频库选择、右侧窗口控制按钮（无交通灯）。

【画布】Desktop 1440×900。

【布局】左右两栏
左侧主区（约 2/3）：
1. 顶部：返回媒体库、番号徽标、标题、元数据状态（已刮削 / 未刮削）
2. 内嵌播放器区域（WebView2 的 video 标签，不是专业播放器皮肤）
   - 封面态：大海报 + 中央播放按钮
   - 播放态：进度条、播放/暂停、音量、全屏、时间码
   - 角标只保留文件属性：4K UHD / HEVC 等，不要「硬件加速转码」
   - HUD 不要：跳过片头、缓冲帧数、转码引擎名
   - 播放失败时显示提示条：「当前格式无法内嵌播放」+「用外部播放器打开」
3. 操作行：继续播放 / 调用外部播放器（候选：PotPlayer、MPC-HC、VLC、系统默认）/ 收藏 / 评分
4. 评分：用户自评 0–5 星，可点选，带「清除评分」。不要聚合评分、不要评价人数
5. 剧照图册：8 张截图缩略图；标题「剧照图册 / 8 张截图」。不要「关键帧捕获」「4K PNG 提取」按钮
6. 时长信息：官方标称时长 vs 文件真实时长，差异写「相差 1m20s」（不要写无损裁切）

右侧检查器（约 1/3）：
- 海报、番号、日期、标题、主演、导演
- 标签 chips（内容向：温泉、中文字幕等，不要站点名）
- 技术参数：视频编码、分辨率、帧率、音频编码、文件大小、文件名、容器写「MP4」
- 物理路径：D:\Cinema\IPX-945\IPX-945-4K.mp4
- 刮削数据源：scraper v3.x（不要写具体站点）
- 编辑 NFO / 重新刮削入口

【二期区块】（视觉可以保留，但必须加浅灰「第二期」角标）
- 媒体多版本列表：每行显示文件名、分辨率、编码、大小（示例：字幕嵌入版 1080p）
- 不要设计自动播放下一部的复杂控件

【示例】
番号 IPX-945，2023-11-14，相泽南，导演 T. Sakamoto，7.82 GB，02:18:40，HEVC/H.265，D:\Cinema\IPX-945\IPX-945-4K.mp4

【禁止】
IINA、Infuse、libmpv、转码、杜比视界色调映射、Metal、聚合评分、站点名、代理、emoji 图标、紫蓝渐变模板。

界面文案简体中文。专业、克制、工作台感。
```

## P06 · 扫描与待处理

```text

4. 刮削异常 · 文件异常 · 5

【候选列表】

【示例行】

【引导态（若同屏可并列小卡）】
无视频库 → 引导添加库根目录；刮削器未配置 → 引导进入刮削器设置

禁止：DMM/FANZA/JAVLibrary 等站点名、匹配度、代理节点、emoji、macOS、紫蓝渐变模板。
```

## P07 · 任务监控

**操作**：Desktop 新屏。

```text
Windows 桌面应用「CineVault Workstation」的「任务监控」页。左侧导航当前选中「任务监控」。完整应用壳。

画布 Desktop 1440×900。

【顶部】
- 标题：任务监控
- 当前任务徽标：运行中 / 已完成 / 已取消 / 异常结束
- 右侧：取消当前任务（危险按钮，旁注「已成功的结果会保留」）

  3. 封含下载
  4. 截图抓取
```
