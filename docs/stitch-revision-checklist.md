## §0 平台基线（每次都要带上）

> 这是一个 **Windows x64 桌面应用**，技术栈 **Go + Wails v2 + WebView2**，非 macOS、非 Web、非移动端。
>
> 硬性要求：
> - 路径用盘符形式，如 `D:\Videos\Library`、`\\NAS\Media`，**不要**用 `/Volumes/...`、`smb://...`
> - 配置文件与数据目录用 `%APPDATA%\videolib\`、`%LOCALAPPDATA%\videolib\drivers\`
> - 刮削器是独立进程 `scraper.exe`，通过 stdin/stdout 的 NDJSON 事件流与主程序通信
> - 窗口用 Windows 原生标题栏（或自绘但**不含**红黄绿交通灯）
> - 快捷键用 `Ctrl+K`，**不要** `⌘K`
> - 外部播放器候选：PotPlayer、MPC-HC、VLC、系统默认关联程序。**不要**出现 IINA、Infuse
> - 图形 API 是 DirectX / D3D11，**不要**出现 Metal
> - **没有** 转码管线，视频由 Go 侧 `/media/` 端点直接供流
> - **没有** 内置 mpv/libmpv 内核，内嵌播放就是 WebView2 里的 `<video>` 标签
>
> 产品名暂定 **CineVault**，窗口标题 `CineVault Workstation`。

## §1 信息架构定稿

侧栏三层分组，共 13 个导航项。**观影与刮削扁平**（高频工作界面，减少点击层级）；**设置保留为一组**。

```
观影 · MEDIA        演员（默认首页） / 全部影片 / 继续观看 / 最近播放
刮削 · SCRAPER      扫描与待处理 / 任务监控 / 异常与修复
设置 · SETTINGS     视频库管理 / 刮削器设置 / 播放器设置 / 环境诊断 / 外观与配置文件 / 关于与更新
```

三项结构决策，请照此执行：

1. **首页第一维度是演员**。「演员」是默认落地页，按演员浏览整个视频库。
2. **「收藏夹」不再作为独立导航项**。收藏降级为「全部影片」页顶部的一个预置筛选 chip，与「未看完」并列。
3. **取消独立的「设置首页」页面**。其职责拆为三处：分组显示 → 侧栏分组标题；配置保存状态 → 全局顶栏指示器；配置文件路径 + 应用数据目录 → 「外观与配置文件」页。

## §7 投喂方式（怎么发）

**不要整份粘贴。** 拆成多轮「模块对话」：每轮只改一件事，成功后截图存档，再开下一轮。§0 平台基线每次开新对话都带；§8 全局约束每次都带；§2 要点消化进当轮「修改点」；§3 / §4 一次只发一屏。Stitch 的硬性机制：

1. **单次 prompt 控制在 5000 字符以内。** 超过会稳定丢组件。
2. **一次只提一个改动。** 把多个改动塞进同一个 prompt，Stitch 会放弃迭代、把整个布局重新生成一遍。
3. **改造页用「对话式修改」，不要重新描述。** 在已有屏幕上直接下指令（"删除右侧继续观看区块"、"把内容区改为两列"）。重新描述 = 丢掉已做好的视觉。
4. **项目建为 DESKTOP 画布**（不是 MOBILE）。
5. **先建 Design System 再逐屏生成。** 色板 / 字体 / 圆角先定死，后续每一屏都挂在这个设计系统下，保证 12 张图一致。
6. **每步成功就截图存档。** Stitch 仍是 beta，设计可能意外重置。截图既能留档，也能作为参考图喂回去恢复或继续迭代。
7. **反 AI 味指令要显式写。** 否则会得到紫蓝渐变 + 三列对称 + emoji 图标的通用模板脸。
8. 语言策略（可选）：结构和技术约束用英文写更稳定，最后加一句让它用简体中文输出界面文案。现有设计稿是中文，也可以直接用中文写下来，但不是每屏都值得这么用。

## §8 全局约束（每次都要粘贴）

> **严格遵守以下约束，不要添加任何未列出的功能：**
>
> **结构**
> - 侧栏固定 13 个导航项，不得增删。分三组：观影（演员 / 全部影片 / 继续观看 / 最近播放）、刮削（扫描与待处理 / 任务监控 / 异常与修复）、设置（视频库管理 / 刮削器设置 / 播放器设置 / 环境诊断 / 外观与配置文件 / 关于与更新）
> - 桌面三栏结构：全局导航侧栏（240–280px） / 主内容区 / 可选右侧检查器
> - 画布 desktop，基准 1440×900，最窄支持 1280×800
> - 顶部自绘窗口控制栏，最小化 / 最大化 / 关闭在**右侧**，不含红黄绿交通灯
>
> **禁止出现**
> - libmpv、mpv、内置播放内核、转码、transcode、杜比视界、Dolby Vision 色调映射、HDR10+ 透传
> - 匹配度、置信度百分比、聚合评分、评价人数
> - 代理设置、代理节点、多站点选择、元数据优先语言
> - 任何具体站点名称
> - emoji 作为图标
>
> **视觉**
> - 图标统一用 Material Symbols Outlined
> - 不使用紫蓝渐变背景；不使用三列对称布局；不交替使用灰底区块
> - 状态语义色沿用现有系统：翠绿 = 正常/已刮削，琥珀 = 警告/缺图，绯红 = 错误/文件异常，天蓝 = 进行中
>
> **文案**
> - 界面文案用简体中文
> - 分组小标题用「中文 · ENGLISH」格式（如「观影 · MEDIA」）
> - 所有路径为 Windows 形式
